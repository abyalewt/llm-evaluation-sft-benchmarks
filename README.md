# LLM Technical Evaluation & SFT Benchmark Suite

This repository showcases production-grade model evaluations, forensic fact-checking audits, and Supervised Fine-Tuning (SFT) golden-reference data creation across technical domains (Full-Stack React/JS, PostgreSQL, and Engineering Literature).

## Repository Overview

- **/01-technical-code-evaluations**: Runtime verification, API hallucination detection, and short-circuit logic debugging.
- **/02-forensic-fact-checking**: Research paper literature validation, author verification, and DOI resolution audits.
- **/03-sft-ground-truth-dataset**: Multi-constraint golden reference authoring under strict lexical bans and schema guidelines.

## Methodology & Evaluation Rubric

All model comparisons follow the standardized 4-part justification architecture:

1. **Verdict Statement:** Quantitative pairwise score.
2. **Constraint Checklist:** Systematic positive/negative rule tracking.
3. **Forensic Evidence:** Quoted runtime errors, AST syntax bugs, or citation proofs.
4. **Operational Impact:** Downstream parser and system failure analysis.
